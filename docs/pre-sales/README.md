# Pre-Sales Sample Set

Working artifacts from how I run a technical sale: discovery, demo, and RFP response. The scenario is the fictional **RJS A/C Quote Calculator** prototype ([repo](https://github.com/johneschwartz1-hub/rjs-ac-showcase)); every customer, name, and figure here is made up for illustration.

| File | What it shows |
|---|---|
| [discovery-call-template.md](discovery-call-template.md) | How I structure a discovery call and what I capture for the demo and SOW |
| [demo-script.md](demo-script.md) | A 15-minute demo built around the customer's workflow, not the feature list |
| [rfp-security-response-sample.md](rfp-security-response-sample.md) | Honest, defensible answers to common security questions, including what is not built yet |

Approach: understand the workflow first, demo only what maps to it, and answer security questions precisely, including the limits.
